# Supermarket Management System

## Overview
A simple C++ console application for managing supermarket products. It allows administrators to add, edit, and delete products, while buyers can view and purchase items.

## Features
- **Administrator:** Add, modify, and remove products.
- **Buyer:** View product list, purchase items, and generate receipts.

## Usage
1. Compile the program using a C++ compiler:
   ```sh
   g++ supermarket.cpp -o supermarket
   ```
2. Run the program:
   ```sh
   ./supermarket
   ```

## File Storage
- Uses `database.txt` to store product details.
